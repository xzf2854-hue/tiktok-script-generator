# TikTok 脚本生成器

一个可直接在浏览器里运行的小网页工具：输入冷知识主题，生成 30–50 秒的 9:16 竖屏 TikTok 分镜脚本。

## 用法

直接用浏览器打开 `index.html` 即可，无需安装、无需联网、无需 API Key。

1. 输入一个冷知识主题，或点选题库里的选题
2. 选目标时长（30–50 秒）、叙事风格、旁白语言和语速
3. 点生成，得到每镜的时间码、旁白文案、画面描述、生图提示词、屏幕大字和转场音效
4. 用手机框播放预览，一键复制脚本，或下载 Markdown
